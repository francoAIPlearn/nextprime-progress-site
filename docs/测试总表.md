# Brightening Face Wash 实拍水感首轮测试总表

日期：2026-04-26

## 测试目标

先验证哪种 `实拍水感` 表达方式最适合 `Brightening Face Wash`，不测人物，不测生活方式场景，只测单产品高质感主视觉。

## 品牌硬边界

- 只用 `Brand Introduction` 第 18-19 页的卖点和成分。
- 可用成分：`Niacinamide`、`BHA`、`Kaolin`
- 可用主概念：
  - `10s Brighter and Clearer Skin`
  - `All-Rounder Brightening`
  - `Brighten. Anti-shine. Clear.`
  - `Dense Pearl Foam`
  - `Power Cleanse`
- 不写品牌页未明确给出的额外功效。

## 固定执行要求

- 比例：`1:1`
- 单产品主视觉
- 冷灰或银灰背景
- 真实水膜 / 水滴 / 冷凝玻璃感
- 银色包材高反射，不压暗，不偏黄
- 文案只保留 `1` 个主标题 + `1` 组短副信息

## 复盘标签

- `赢`
- `输`
- `持平`
- `高点击低转化`
- `低点击高转化`

## 判读规则

- `赢`：点击更好，且 `ROAS / CVR` 不劣化
- `高点击低转化`：保留水感方向，优先改承接文案和产品证据
- `低点击高转化`：保留卖点结构，优先改首屏冲击和标题可读性
- `持平`：不继续耗预算，下一轮换更明显变量
- `输`：该变量停测，不重复修同一版
