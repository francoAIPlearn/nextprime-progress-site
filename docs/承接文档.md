## 2. 固定工作流

先按下面这条轻量流程执行：

1. `方向梳理`
   明确这一轮想打什么方向，例如产品证据、功效卖点、人物场景、品牌感表达。
2. `变量拆解`
   每轮只拆一个主变量，避免多变量混在一起看不出结论。
3. `AB 测试方案`
   先定义控制组、变化组、假设、观察指标和下一步动作。
4. `资产检查`
   检查产品图、品牌规范、人物素材、尺寸要求是否齐。
5. `测试图需求单`
   把每张图要做什么写清楚，再进入出图。
6. `出图`
   按需求单执行，不临时改测试变量。
7. `复盘迭代`
   用统一指标和结果标签判断是放大、微调还是停掉。

## 5. AB 测试与复盘最小模板

### AB 测试最小字段

每组测试先按下面字段记录：

| 字段 | 说明 |
| --- | --- |
| 测试编号 | 本轮测试唯一编号 |
| 测试目标 | 这轮是为了提点击、提转化还是验证新方向 |
| 控制组 | 当前基准版本 |
| 变化组 | 本轮变化版本 |
| 唯一变量 | 只改一个主变量 |
| 假设 | 为什么认为这个变化会更好 |
| 需要资产 | 做这组图必须具备的资产 |
| 观察指标 | 重点看哪些指标 |
| 结果标签 | 跑完后统一标记 |
| 下一步动作 | 下一轮怎么处理 |

### 观察指标

当前复盘先统一看这 4 个核心指标：

- `CTR`
- `CTR (link click)`
- `CVR`
- `ROAS`

### 结果标签

当前先用最小标签集：

- `赢`
- `输`
- `持平`
- `高点击低转化`
- `低点击高转化`

### 复盘迭代规则

- `赢`
  保留主变量，下一轮只做小迭代。

- `输`
  先判断是方向错还是变量错，再决定换方向还是换表达。

- `持平`
  先看成本和放量潜力，再决定是否继续。

- `高点击低转化`
  优先改卖点表达、产品证据、承接内容。

- `低点击高转化`
  优先改首屏、标题、钩子表达，不先动核心卖点。
