素材生产资产：文案、画面、Prompt 逻辑

本轮有效文案分析

  • 高转化文案不是讲品牌，而是讲状态变化。 例如“暗沉疲态到清爽提亮”“Fresh look starts here”都在承诺使用后的脸部状态。
  • 强视觉词能带动理解。 “Ice / Cool / Dense pearl foam / Brightening”这类词能直接对应画面，不需要用户读长文案。
  • 男性语境有效。 “for men”“pria”“after work”“oily face”把产品从普通洁面拉回男性场景，降低理解成本。
  • 成分文案需要结果翻译。 Niacinamide、BHA、Kaolin 不要单独摆成科普，要翻译成 brighter look / clean pores / oil control。

文案结构模板

  • 痛点开头：OILY FACE AFTER WORK? / WAJAH KUSAM?
  • 结果承诺：Fresh, brighter-looking skin / Feel cool clean / Smooth rough texture
  • 证据支撑：Niacinamide + BHA + Kaolin / Dense pearl foam / KOL recommendation
  • 收尾动作：Try the fresh cleanse / Start with one wash / Clean pores daily

画面与文案匹配原则

  • 提亮类：必须配人脸前后状态或亮度变化，不要只放产品。
  • 冷感类：必须配冰、水珠、浅蓝光感，让“cool”一眼可见。
  • 泡沫类：必须配泡沫微距和产品并列，证明质地。
  • 成分类：必须配 3 个小模块，且每个成分后面跟结果利益点。

2. 再给结果标题要承诺一个可视化结果：fresh / bright / cool / clean / smooth。
3. 画面证明用人脸前后、泡沫、冰水、成分模块证明标题，不要让文案和画面各讲各的。
4. 产品收口产品必须清晰且不变形，放在结果旁边，让用户把效果归因到 NEXT PRIME MEN。
