Data Flow / 审图评论

审图评论到 BigQuery 数据流

这个页面用于判断“评论系统是否可作为正式数据链路”。可视化基于当前代码实现：前端评审组件 + Cloud Run review-sync API + GCS 存储；BigQuery 作为分析层建议新增定时入仓任务。

总览首页 出图评审 测试4文档 数据流说明

当前结论

  • 前端评论字段（勾选/评分/文字）会实时同步到 Cloud Run API。
  • 附件先尝试上传共享存储（GCS），失败时退回浏览器本地缓存。
  • 目前服务端主存储是 GCS JSON + 附件对象，不是直接写 BigQuery。
  • 要做报表分析，建议补一个 Cloud Run Job / Scheduler 把 JSON 增量落到 BigQuery 明细表。
