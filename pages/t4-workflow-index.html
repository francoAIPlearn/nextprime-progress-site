方向梳理

Product Identity Waterfeel Reference Master Table

I 系列

以“半浸水 / 水线 / 折射 / 局部进入水体”为核心，重点看产品仍然保持主体地位时，哪些低冲击水感更高级。

适合观察 calm waterline、meniscus、glass-water plane、studio tank edge 等细分母体。

H 系列

以“击打 / 扫过 / 水幕 / 水柱 / base splash”为核心，重点看更强冲击感下，产品完整性和可读性能否保住。

适合观察 arc、curtain、jet、base splash、frame impact 等更激进的水感表达。

变量拆解

本轮的唯一主变量是 `water behavior`。这些元素固定不变：产品身份、银色包装、冷灰 / 银灰棚拍调性、`1:1` 尺寸、产品必须保持 dominant and readable。
